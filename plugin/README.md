# NovaVisualsTag

Плагін для Spigot/Paper 1.18.2. Показує **NV** після ніка гравців, які грають із модом Nova Visuals
(список Tab і чат; над головою — за бажанням у config.yml).

## Встановлення
1. Збірка з GitHub: вкладка Actions → Releases → `NovaVisualsTag.jar`.
2. Поклади `NovaVisualsTag.jar` у папку `plugins` сервера й перезапусти сервер.
3. Налаштування: `plugins/NovaVisualsTag/config.yml`, після змін — команда `/nvlist reload`.

## Як працює
Мод Nova Visuals (версія 0.5.5 і новіша) через пару секунд після входу надсилає серверу службове
повідомлення в каналі `novavisuals:hello`. Плагін його ловить і ставить мітку. Без цього моду
мітки не буде. Вимкнути надсилання можна в меню мода (Configs → Show NV Tag).

Команда `/nvlist` — список гравців з Nova Visuals (потрібне право `novavisuals.admin`, за замовчуванням оп).

## Velocity / BungeeCord
Плагін ставиться на **кожен Paper-сервер за проксі** (не на сам Velocity). Мод при вході викликає
службову команду `/nvhello`, яка проходить через проксі, тому працює і з Velocity.

## Чат-плагін
За замовчуванням `chat-mode: auto`: NV дописується після ніка в готовому повідомленні, у який би формат
його не перетворив чат-плагін. Якщо не спрацювало, спробуй `chat-mode: displayname`.
