# Nova Visuals Launcher 1.0.0

Minecraft Java лаунчер на Electron. Працює лише з Fabric (1.18.2 і 1.21.11).

- Мод Nova Visuals для Fabric 1.18.2 (папка `fabric/`): меню на правий Shift, ефекти, HUD, косметика
- Бібліотека модів і ресурс-паків (Modrinth), власні файли, «Системні» файли лаунчера не видаляються
- Офлайн-нік і вхід через Microsoft, скіни, налаштування RAM і роздільної здатності
- Автозбірка Windows-інсталятора на GitHub (`.github/workflows/build.yml`)

Мод для 1.21.11 ще не готовий: Fabric 1.21.11 і бібліотека модів працюють без нього.
