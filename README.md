# Nova Visuals Launcher 1.1.1

Minecraft Java лаунчер на Electron. Працює лише з Fabric (1.18.2 і 1.21.11).

- Мод Nova Visuals для Fabric 1.18.2 (`fabric/`): меню на правий Shift, ефекти, HUD, косметика, **«Гравці поруч»** (клавіша V: список / карта / картки)
- Мод для 1.21.11 (`fabric-1.21.11/`): меню на правий Shift (HUD, «Гравці поруч», друзі через сайт) і команди `/nova ...`
- **Сайт і API** (`server/`): акаунти, підтвердження лаунчера, друзі, онлайн/офлайн. Див. `server/README.md`
- Вхід через сайт: Профіль → «Увійти через сайт»; сторінка «Друзі» в лаунчері
- Бібліотека модів і ресурс-паків (Modrinth), офлайн-нік і вхід через Microsoft, скіни, RAM і роздільна здатність
- Автозбірка Windows-інсталятора на GitHub (`.github/workflows/build.yml`)

Меню в 1.21.11 простіше за 1.18.2 (звичайні кнопки Minecraft, три вкладки: HUD, Гравці, Друзі). Команди теж працюють: `/nova mode list|map|tags`, `/nova range`, `/nova friends`, `/nova add|accept|remove <нік>`.

Якщо мод 1.21.11 не збереться, збірка інсталятора все одно пройде, але без цього мода: дивись job `mod121` у GitHub Actions.
