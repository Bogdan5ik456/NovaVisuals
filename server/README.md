# Сайт і API Nova Visuals

Без залежностей, потрібен лише Node 18+.

```
cd server
node server.js          # http://localhost:3000
```

Змінні: `PORT`, `DATA_FILE` (де зберігати дані, за замовчуванням `server/data.json`).

## Що вміє
- Реєстрація й вхід (нік + пароль, пароль зберігається як scrypt-хеш).
- **Підтвердження лаунчера**: лаунчер просить код → відкриває `/link?code=XXXX-XXXX` → ти входиш на сайті й тиснеш «Так, це я завантажив лаунчер» → лаунчер отримує свій токен.
- Друзі: запит, прийняти/відхилити, видалити. Статус онлайн/офлайн, у грі чи в лаунчері, на якому сервері.
- Присутність: лаунчер шле «я онлайн» раз на 30 с, мод у грі раз на 10 с.

## Публікація
Потрібен хостинг із Node (VPS, Render, Railway, Fly.io тощо) і **HTTPS** (на хостингу зазвичай автоматично або через Caddy/nginx).
Після публікації вкажи адресу в лаунчері: Налаштування → «Адреса сайту Nova Visuals»
(або змін `DEFAULT_SITE` у `core/site.js` перед збіркою).

## Безпека
- Токен лаунчера лежить у `%APPDATA%\Nova Visuals` (шифрується Windows) і в `config/novavisuals-link.json` у папці гри. Цей файл читає мод, тож **не став невідомі моди**. Кнопка «Вийти скрізь» на сайті скасовує всі токени.
- Присутність не публікує координат: друзі бачать лише онлайн/офлайн і назву сервера.
- Обмеження частоти на вхід, реєстрацію й підтвердження коду вбудовані. Дані тримаються в одному JSON-файлі: для сотень гравців це нормально, для тисяч заміни на базу даних.
