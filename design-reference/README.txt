Nova Visuals — design asset reference pack

Files:
- nova-visuals-assets-overview.png: full design sheet
- numbered PNG files: cropped reference sections from the sheet

Important:
These are visual reference images/crops, not production-ready transparent sprites.
For the launcher UI, use them as design references or slice/redraw individual icons.
For Minecraft resource-pack textures, individual sprites should be recreated as pixel-art PNGs at the required exact dimensions.
Palette shown in the reference:
#0B0B0F, #14141A, #1E1B2E, #7A2CF7, #B855FF, #E0A3FF, #FFFFFF
